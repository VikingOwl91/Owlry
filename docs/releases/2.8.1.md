# Owlry 2.8.1

Owlry 2.8.1 fixes socket-activated upgrades from 2.7.0. The Arch package now
migrates active sockets at the packaged default path automatically. Normal
upgrades in this configuration should not need manual recovery.

## What changed

The 2.7.0 daemon replaced systemd's socket file and removed it again when it
stopped. During an upgrade, this could leave an active socket unit with no
reachable socket path. Restarting only the daemon did not restore the path.

The package now stops the old daemon and socket together before recreating
the listener. It checks running user managers independently, leaves healthy
sockets and deliberately inactive units alone, and keeps pending state if a
migration is interrupted. The daemon also reports a missing inherited socket
with recovery guidance.

## Upgrading

Update the Arch package normally:

```bash
paru -Syu owlry
```

The automatic migration applies to active systemd sockets using the packaged
default path. If you run only `owlry.service`, restart it after upgrading:

```bash
systemctl --user restart owlry.service
```

If you start the daemon manually, stop the old process and start it again.
Custom socket paths require manual upgrade handling. The UI and daemon must
use the same version.

Check pacman output for migration failures. The package transaction has already
completed when migration runs, so a migration failure does not roll it back.
If a default-path migration was interrupted, retry as the affected user:

```bash
systemctl --user start owlry-user-migrate.service
```

See the [upgrade guide](https://somegit.dev/Owlibou/owlry/src/tag/owlry-v2.8.1/docs/upgrading.md)
for custom paths, recovery and upgrades from 1.x.

## Verification scope

The release candidate was tested for fresh installation and upgrade from a
source-exact rebuild of 2.7.0 on a pinned Arch guest with cached Arch/ALHP
dependencies. These checks cover daemon activation, IPC and migration,
including interruption and recovery. Full Wayland GUI behavior and every
Arch dependency combination were not tested.
